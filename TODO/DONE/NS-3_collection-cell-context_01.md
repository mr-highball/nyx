The saved Service monitor's Shift+F10 opens its ordinary managed cell menu.
The public context callback exposes table identity and pointer information, but
no portable exact row, typed field or accepted scalar. An author adding an action
such as "restart this service" must otherwise inspect platform controls or guess
from selection. Selection and the clicked/context cell are different concepts.

Add an owned typed cell snapshot to canonical context events, captured through
the original prepared input before application callbacks. Reuse existing cell
capture, menu and cancellation machinery. It grants no clipboard, mutation or
future execution authority. This is a prerequisite of W2's authored actions and
stable typed event payload, with no separate completion credit.

**Acceptance Criteria:**

- Context callbacks on ordinary and arranged browser/LCL tables identify the
  exact accepted item, typed field, original source revision and raw scalar.
  Pointer and keyboard context invocation agree. Visible coordinates, selected
  rows, formatted text and unfinished drafts cannot substitute for that cell.
- Retained/copy/scheduled event snapshots own their data after edits, filtering,
  reordering, replacement and retirement. Preserve Unicode/NUL, Boolean, integer
  and finite number values without coercion. Default/absent context is explicit.
- Capture belongs to the original canonical envelope. Consumed, stale, nested,
  disabled or retired input cannot borrow a newer context. No second source read,
  clipboard request engine, physical event or menu default is manufactured.
- Existing interfaces/alternative mounts remain compatible. No DOM/LCL object,
  store, mount, callback or authority token is retained in the public snapshot.
  Existing event payloads, observers, multiple registrations and scheduling stay
  usable. Unmanaged/default-off editor context remains honest about absence.
- Demonstrate a useful authored custom action through ordinary Nyx menus and
  callbacks in the saved/generated Service monitor, with semantic Studio
  authoring/build and actual controls at measured wide/compact sizes. Retain
  before/after failure evidence, existing regressions, clean native heaps, exact
  project/history/output choices and clipboard contents. Distinguish widget/
  browser-driver input from physical/assistive qualification.

Broader cell payloads on other event families remain with the parent workbench's
original criteria; this task does not assert them from context-menu delivery.
