# NS-1_source-projection_01 — Compiler-executed source projection

[North stars](../../MILESTONES.md) · [Task catalog](../README.md) · [Task flow](../../TASKFLOW.MD)

**Description:**

Supply the missing execution prerequisite for original NS-1_codegen_01 criterion
three. The strict importer preserves helpers but cannot evaluate arbitrary
Pascal expressions or construction routines. Use the actual compiler to execute
the complete submitted unit's BuildNyxDocument, returning an independently owned
validated design with exact source and target identity. This is an explicit host
execution API, not admission of files/MCP payloads or publication of editor state.
Credit remains pending assessment; this split does not reduce the original
source/design synchronization, ordinary editor or semantic workflow requirements.

**Acceptance Criteria:**

- A documented portable typed projection result separates compilation,
  execution and design admission. Exact submitted source, compiler diagnostics
  and target remain independent of documents/renderers and machine paths.
- The existing Pascal compiler executor supplies an explicit projection path
  without running the strict builder interpreter first. Native execution owns
  its child/family, artifacts and bounded byte result. Browser compilation emits
  an owned Pascal worker producer using the same document/codec contract.
- Actual FPC and HTTP pas2js execution of the same complete handwritten unit
  exercise helper expressions, class methods, loops, reusable construction,
  state/resource values and dedicated Unicode qualification. Both reconstruct
  the exact complete expected design; compilation alone does not establish this.
- Compiler/type failure, throwing constructors, unavailable tools, malformed or
  excessive returned data and cancellation refuse without exposing a usable
  design. Native lifetime checks retire owned children and report no heap leaks.
- A maintained Pascal consumer and build orchestration reproduce the compiler
  and execution evidence. No protected project, live endpoint or global/user
  enrollment is changed. Document subsequent paired admission/reconciliation,
  editor HTTP/MCP integration and preserving rollout as required original work.

## Accepted execution prerequisite — 2026-10-10

The public immutable projection/build interfaces distinguish exact source, typed
target/state, compiler diagnostics, native execution log and compiled-only browser
worker receipts. Independent document copies survive result/executor release.
The explicit executor path bypasses the strict fluent reader, owns fixed-argument
compilation/execution and bounds result byte allocation before admission. Native
model evaluation needs no widgetset/display; browser producers are Pascal workers
with the matched embedded RTL.

Maintained checked FPC qualification passes **55** assertions; actual HTTP browser
execution passes **33**. The exact complete handwritten constructor uses helper/
class methods, arithmetic, a loop, two pages, reusable controls, scalar defaults
and text/JSON resources. An independent literal expected design agrees exactly,
including supplementary/combining Unicode. Throwing/nil constructors run on both
targets; type errors produce both ordinary compiler reports. Native also checks
unavailable compilers, pre-start cancellation on both requested targets, deadline
retirement and cancellation after the constructor's physical execution marker.
Both receive paths refuse malformed, mismatched and excessive data without a
usable tree. Checked native producer/consumer/HTTP driver report zero heap leaks.

The maintained build target stages Pascal consumers and explicitly qualifies a
new runtime. Actual HTTP execution is observed separately. The isolated host was
retired after exact four-field identity verification; no projection process or
listener remains. Fresh authenticated read-only preflight retains nine protected
contexts, idle jobs and 23 installed tools. Production LAN/recovery/enrollment
remain unchanged. See the [public guide](../../docs/source-projection.md) and
[packet](../../WORK.md#current-return-path-compiler-executed-source-projection--2026-10-10).
