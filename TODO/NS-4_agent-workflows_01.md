# NS-4_agent-workflows_01 — Primary semantic Studio workflows

[Milestones](../MILESTONES.md) · [Task catalog](README.md) · [Work](../WORK.md)

**Description:** Extend the accepted MCP foundation into the user's primary
agent workflow for composing demos, authoring behavior and validating builds.
The authenticated, bounded, revision-aware document tools are accepted under
[semantic agent operation](DONE/NS-4_agent-tools_01.md). This task owns additional
semantic operations and maintained agent journeys; it does not transfer completion
credit from source, events, state, compiler service or native Studio owners.

Starting evidence: eleven initialized tools; actual desktop/user-scope Codex
discovery; real selected-design queries; 55 HTTP/MCP checks; explicit registration
and credential rotation with 22 preservation/refusal checks and zero leaks.
Native Codex handles in an already-running chat require client reconnection on
the present Windows installation; the Pascal semantic client is usable immediately.

**Acceptance Criteria:**

- Project/user configuration discovers authenticated tools through actual Codex
  initialization, refreshes enrolled credentials on Studio launch and preserves
  unrelated files. The guide distinguishes configured, connected and active-chat
  inventories. This bounded installation criterion has current evidence.
- Maintained demos use bounded semantic inspection, one revision-aware transaction
  per related edit and selective previews, with observable editor changes and
  protected user work. Browser/LCL input consumers qualify physical behavior.
- Callback creation, ordered registrations, execution policy and warned removal
  are semantic operations on the same admitted paired source/history boundary as
  the inspector, retaining drafts and exact owner/event identities.
- Agents can request view/reusable/application builds through structured tools,
  inspect bounded job status and diagnostics, and validate artifacts against the
  exact source/revision/output. Tool requests cannot inject compiler commands.
- Owned demo/review work can be created and cleaned up without replacing an active
  user design. Root cleanup, state/bindings and reusable workflows expose supported
  semantic operations with explicit ownership, revision and refusal behavior.

**Blockers:**

- [Semantic agent operation](DONE/NS-4_agent-tools_01.md), accepted.
- Underlying callback/state/source/build behavior remains with its existing owners;
  expose only qualified operations and retain their original acceptance criteria.
