76-kind focus/keyboard qualification. It covers every `TNyxAttribute`, including
attributes retained in the expanded inspector. Metadata completeness alone does
not establish a rendered effect. The 35 compound recipes inherit the physical
properties of their expanded parts; a caption on a layout root does not become
a visible caption merely because a child has one.

The integrated repair exercises the nine affected physical families
(select/list/table/tree/input/code/group/image/progress), common layout transitions
and surface clearing. One MCP-composed catalog companion is exported in bounded
windows and compiled unchanged for browser and LCL. A maintained Pascal consumer
checks initial state, mutation, clearing and unrelated/no-op synchronization,
including focus, literal selection, silent programmatic updates, and attachment
ownership. Existing focused packets remain evidence for unchanged boundaries.

The MCP-authored revision-8 companion covers all 76 kinds and 262 expanded faces.
Native execution passes 14,127 checks with zero leaks; executed browser passes
14,269 at desktop and 14,270 inside an actual 390-pixel viewport. Both real
application compiler files equal the exported companion bytes. Shared detached
edit admission resolves complete contextual properties before checking the
original JSON types, so selector/value member order cannot change meaning.
Wrong types retain the entire paired source/design and history. Portable native
and executed-browser admission pass 39 each; real MCP passes 75.

Selective rendering found that PNG dimensions previously did not establish the
requested CSS viewport. The immutable preview now carries both dimensions and
renders in an exact-size child viewport. Capture requires measured width, height
and revision to agree. An MCP-authored mobile preview was inspected after the fix;
its input, source face and correctly ranged progress fit the admitted width.
See [the current work record](../WORK.md) for artifacts and deployment evidence.

This does not close criterion 1 or establish complete property/target parity.
Native resource providers, general flex/hidden-layout semantics, production
component depth, complete accessibility and native Studio retain their original
owners and acceptance requirements. No support grade is lowered to conceal a
failed advertised effect.
